Daily summary card: calories logged vs target, three macro bars, expandable micronutrients.

```jsx
<DailySummary kcal={1240} target={2100} protein={{ value: 64, target: 120 }} carbs={{ value: 142, target: 240 }} fat={{ value: 41, target: 70 }} micros={[{ label: 'Fiber', value: '18 g' }]} />
```
